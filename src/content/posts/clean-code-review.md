# 읽게 된 계기

코드 리뷰 중에 "가독성"과 "의도"에 대한 이야기가 자주 나와서, 관련해서 정리가 잘 된 책을 찾다가 읽게 되었습니다.

## 느낀 점

- 함수는 한 가지 일만 해야 한다는 원칙이 실제 리팩터링 습관에 큰 영향을 줬습니다.
- 이름 짓기에 들이는 시간이 아깝지 않다는 걸 다시 확인했습니다.
- 예제 코드가 다소 오래된 스타일이라 그대로 적용하긴 어렵지만, 원칙 자체는 여전히 유효합니다.

## 한 줄 요약

코드는 결국 사람이 읽는다는 것을 계속 상기시켜주는 책.
